# Web Today I Learned (나만의 프로필 & TIL 페이지)

나를 소개하는 프로필 페이지와 매일의 학습 기록(TIL)을 남길 수 있는 웹 페이지를 구현하는 미션입니다. HTML로 뼈대를 잡고, CSS로 스타일링하며, JavaScript로 동적인 기능을 추가합니다.

---

## 실습 환경 구축
- [ ] `web-today-i-learn` 저장소를 자신의 계정으로 **Fork** 한다.
- [ ] Fork한 저장소를 로컬 환경에 **Clone** 하여 미션을 진행한다.

---

## 미션 진행 단계

### 1단계 - HTML로 뼈대 잡기

#### 기능 요구사항
- [ ] **프로필 영역**: 나를 가장 잘 소개하는 사진(`<img>`), 닉네임, 한 줄 소개를 구성한다.
- [ ] **기본 정보**: 이름, MBTI, 취미, 좋아하는 음식 등 자신의 기본 정보를 표(`<table>`)로 정리한다.
- [ ] **자기소개**: 자신을 소개하는 글을 단락(`<p>`)으로 작성하고, 관련 링크(블로그, GitHub 등)를 `<a>` 태그로 연결한다.
- [ ] **나만의 갤러리**: 부제를 짓고, 자유 주제(기억에 남는 여행지, 요리 등)로 9가지 사진을 정사각형으로 배치한다.
- [ ] **나를 울린 인생 작품**: 자유 주제로 최소 2가지를 목록(`<ul>` 또는 `<ol>`) 형태로 소개한다. (작품 중 하나는 트레일러 등 관련 영상을 `<video>` 또는 `<iframe>`으로 삽입)
- [ ] **TIL (Today I Learned)**: 오늘 새롭게 배운 내용(날짜, 학습 주제, 내용)을 기록하는 섹션을 구성한다. (나의 생각이 어떻게 변했는지 볼 수 있도록 1줄 회고를 함께 남겨보는 것을 추천합니다!)
- [ ] **상단 내비게이션**: 각 섹션으로 이동할 수 있도록 `<a>` 태그로 페이지 내 하이퍼링크를 설정한다.
- [ ] 요구사항에 없는 내용은 스스로 판단하여 자연스럽게 구현한다.

#### 프로그래밍 요구사항
- [ ] root 디렉터리에는 **웹 문서만** 저장한다.
- [ ] `<head>` 태그 안에 HTML 인코딩 방식(`<meta charset="utf-8">`)을 삽입한다.
- [ ] `<head>` 태그 안에 뷰포트 설정(`<meta name="viewport" content="initial-scale=1, width=device-width">`)을 삽입한다.
- [ ] `<title>` 태그 안에 적절한 제목을 삽입한다.
- [ ] Open Graph 메타 태그(`og:title`, `og:description`, `og:image`)를 최소 1개 이상 설정한다.
- [ ] 시멘틱 태그(`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`)를 적절히 활용한다.
- [ ] 본문 영역은 `<h1>` ~ `<h6>` 태그를 사용하여 제목 계층 구조를 지킨다.
- [ ] `<img>` 태그에는 반드시 `alt` 속성을 작성한다.
- [ ] 리소스 경로(이미지, CSS 등)는 **상대 경로**로 지정한다.
- [ ] `images` 디렉터리에는 이미지 파일만, `css` 디렉터리에는 스타일링 파일만 저장한다.

---

### 2단계 - CSS로 꾸미기

#### 기능 요구사항
- [ ] CSS는 별도 파일(`.css`)로 분리하여 `<link>` 태그로 연결한다.
- [ ] 태그 선택자, 클래스 선택자(`.`), ID 선택자(`#`)를 각각 **1회 이상** 사용한다.
- [ ] 나만의 갤러리 이미지 9장을 **CSS Grid** 또는 **Flexbox**를 활용하여 배치한다.
- [ ] 제공되는 템플릿 레이아웃을 따르되, 본인이 원하는 대로 자유롭게 스타일링한다.

---

### 3단계 - JavaScript로 동작 추가

#### 기능 요구사항
- [ ] JavaScript는 별도 파일(`.js`)로 분리하여 `<script>` 태그로 연결한다.
- [ ] TIL 섹션에 **작성 폼**을 추가한다. (`<form>` 태그 안에 날짜 및 제목 `<input>`, 내용 `<textarea>` 구성)
- [ ] 각 입력 요소에는 `<label>` 태그를 연결한다.
- [ ] 등록 버튼(`<button>`) 클릭 시, **이벤트 리스너**를 통해 입력 내용을 받아 TIL 목록에 추가한다.
- [ ] `document.querySelector()` 등을 활용하여 DOM 요소를 선택하고 제어한다.
- [ ] **(선택)** 기본 요구사항 완료 후 추가 기능 구현 (예: 다크 모드 토글, 갤러리 이미지 클릭 시 확대, 스크롤 애니메이션 등)
